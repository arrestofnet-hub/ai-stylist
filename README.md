# AI Stylist

Персональный AI-стилист и виртуальная примерочная.

## Цель MVP

Пользователь один раз создаёт профиль и загружает референсные фотографии, после чего может:
- примерять одежду;
- менять только один элемент образа;
- подбирать причёски;
- сохранять предпочтения;
- получать персональные рекомендации;
- использовать бесплатный лимит и платные кредиты.

## Принципы проекта

- Полностью отдельный проект от `ai-lawyer`.
- Отдельные переменные окружения, база, пользовательские данные, фото и логи.
- Сохранение лица и пропорций пользователя — приоритет №1.
- Минимальная инфраструктура и низкая себестоимость.
- FastAPI backend.
- API-ключи никогда не хранятся в GitHub.

## План MVP

1. Backend + health endpoint.
2. Профиль пользователя.
3. Загрузка референсных фото.
4. Try-on одежды.
5. Try-on причёски.
6. Изменение одного элемента без перегенерации всего образа.
7. Бесплатный лимит / кредиты.
8. Подключение к ChatGPT через MCP.
